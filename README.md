# Hi, I'm Leonardo Santos 👋

I build automations, data analyses and web systems with AI. I'm based in Brazil and open to remote roles.

My background is in Business Administration and fixed-asset management: I was the asset manager (Gerente de Patrimônio) of a bioenergy plant. That's why my data projects start from real business problems, like inventory control, depreciation and request triage.

## Featured projects

- **[Asset Management Dashboard with AI](https://github.com/Leocpsantos/gestao-patrimonial-ia)** · [live dashboard](https://leocpsantos.github.io/gestao-patrimonial-ia/)
  A fictional inventory of 1,500 assets in SQLite, analyzed with SQL and pandas: straight-line depreciation (Brazilian tax rates), book value by department, write-offs and critical assets. Google Gemini writes an executive summary from the aggregated numbers. Static dashboard on GitHub Pages, tested with pytest.
- **[Asset Request Triage with n8n and AI](https://github.com/Leocpsantos/triagem-chamados-n8n)**
  An n8n automation: requests arrive by form or webhook, Gemini classifies type, urgency, department and asset tag with structured output, and everything goes to an n8n Data Table. A second workflow writes a daily report for the manager.
- **[Atalho IA — Website](https://github.com/Leocpsantos/atalho-ia-site)** ([atalho.ia.br](https://atalho.ia.br))
  Website for my AI solutions business, in vanilla HTML, CSS and JavaScript. It has an animated mascot with an in-browser assistant (no server, no API costs), a command palette and an interactive "shortcut map".
- **[Altrão & Pocibom Advogados — Website](https://github.com/Leocpsantos/site-altrao-pocibom-advogados)** ([live](https://altraoepocibomadv.com.br))
  Institutional website for a law firm in Brazil, published with the firm's authorization. Responsive, with SEO and a contact form that sends straight to WhatsApp.
- **[agentes-painel](https://github.com/Leocpsantos/agentes-painel)**
  A live panel for Claude Code that shows what the main session and each subagent are doing. TypeScript plugin with hooks.
